# Game Library

Every game I have access to, where it lives, searchable from anywhere.

- `index.html`: the viewer (GitHub Pages serves it)
- `games.json`: the library, generated by `scan.ps1` (don't hand-edit)
- `manual.json`: games the scanner can't find. Edit this one by hand
- `config.json`: NAS paths, hidden titles, ROM platform names
- `config.local.json`: Steam API key. Never committed

## Refresh the list

Double-click `scan.cmd`, or run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scan.ps1 -Push
```

It reads Steam, Epic, GOG/Battle.net/Ubisoft/EA installs, the Turiya shares and `manual.json`,
writes `games.json`, and pushes it. If Turiya or the Steam API can't be reached,
their entries from the previous scan are kept.

## Steam: full library, not just installed

1. Get a key at <https://steamcommunity.com/dev/apikey> (any domain name works, e.g. `localhost`).
2. Paste it into `steamApiKey` in `config.local.json`.
3. If the scan says Steam returned no games, set **Game details** to Public in Steam's privacy settings.

## Adding games by hand

```json
{ "title": "Anachronox", "store": "GOG", "platform": "PC" }
```

Optional fields: `where`, `path`, `installed`, `note`. Same title in several sources merges into one game.

## What's left out

Subscription games (Game Pass, EA Play, Ubisoft+, PS Now, World of Warcraft) and Steam tools
(SteamVR, redistributables, Proton, Wallpaper Engine). Edit `hideTitles` / `hideAppIds` in `config.json`.
